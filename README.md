# Sympathy for the Devil

*A narrative-driven game combining visual novel storytelling, rhythm-based gameplay, and interactive puzzles, developed in Unity.*

## Project Overview

**Engine:** Unity  
**Programming Language:** C#  
**Genre:** Visual Novel / Rhythm Game / Puzzle

The game integrates interactive storytelling with rhythm challenges, puzzle mechanics, animated sequences, and branching gameplay experiences.

## My Contributions

- Game mechanics and level design
- Unity scene construction and UI development
- Visual and audio asset integration
- Gameplay testing and debugging
- Parameter adjustments and gameplay refinement

## Technical Implementation

The project includes several gameplay systems:

- **Dialogue System:** Text progression and interactive storytelling
- **Rhythm Game:** Keyboard input, note timing, and hit detection
- **Puzzle System:** Drag-and-drop interactions and completion detection
- **Animation & Audio:** Frame-based animation and audio playback
- **Game Management:** Scene transitions, UI interactions, and gameplay states
